Additive over v1.0.0: no route, field or exported API was removed or changed in meaning.

## Selling to businesses (ext/b2b, `-b2b`)
- Companies, buyers in roles, credit limits, orders on account, approvals and quotes.
- Dealers: territories by country, state and postcode prefix; the storefront's dealer form routes each lead to the most specific dealer, and the store reads, searches, narrows and reassigns leads.
- Bulk ordering: a quick order by SKU, a repeat order, and a partial checkout of chosen lines.
- Find a business order by its PO number, and mark several paid at once.
- Panel screens for business customers, dealers and territories.

## Multi-tenant mode (`gocommerce platform`)
- One process and one PostgreSQL database serve many stores, each an unchanged engine, by host or by the `X-Store` header on a shared API host (D70).

## Pricing and checkout
- A customer group's prices follow an address something proved (`carts.verified_email`), not one somebody typed (D66).
- A module may refuse a checkout before the order exists, and an operator may agree a line's price (D68).
- A state is read by its code or its name, everywhere a rule names one (D72).

## Operations
- Public demo mode: personal data masked on admin responses, sign-in routes frozen (`-demo`).
- The OpenAPI contract resolves, and no longer closes the set of error codes.

## Panel
- Import shows the pictures it links; the Vendors screen works again; selects match the height of the text boxes beside them; a newly added buyer is masked and named correctly.

Upgrading: run the new binary; its migrations apply on start.
